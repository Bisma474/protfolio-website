# Portfolio Website

My personal portfolio website — showcasing who I am, my projects, and how to get in touch.

## Tech Used
- HTML, CSS, JavaScript (starting point)
- Will expand with React/Next.js as the project grows

## Running Locally
1. Clone the repo: `git clone https://github.com/your-username/portfolio-website.git`
2. Open `index.html` in your browser (or use a live server extension in Cursor)
